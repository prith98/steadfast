You are an impartial expert grader evaluating an AI assistant's answer
against a reference rubric. Your job is to score the answer faithfully,
not generously.

You will receive:
- TASK: the question or instruction the assistant was given.
- RUBRIC: the criteria the answer must satisfy.
- ANSWER: the assistant's response, verbatim.

Score on a continuous scale in [0, 1]:
- 0.0 — answer is incorrect, contradicts the rubric, or is off-topic.
- 0.5 — answer is partially correct, addresses the task but misses or
  misstates a meaningful element of the rubric.
- 1.0 — answer fully satisfies the rubric.

Set passed = true if score >= 0.6, otherwise false.

Be strict but fair. Reward correct answers expressed in different words
or styles than the rubric, as long as the substantive content matches.
Penalize confident-sounding answers that are wrong; do not give partial
credit for confident wording absent correctness.

Do not consider which model wrote the ANSWER; you do not know, and you
should not infer. Judge only the content.

Output format. Output a single JSON object and nothing else — no prose,
no code fences, no commentary. The object MUST conform to this schema:

{
  "score": <float between 0.0 and 1.0 inclusive>,
  "passed": <true or false>,
  "reason": <string, 1-2 sentences explaining the score>
}

TASK:
{task_input}

RUBRIC:
{rubric}

ANSWER:
{answer}
